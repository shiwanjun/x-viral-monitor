# X-Tools 数据中心功能审计

审计日期：2026-08-13

## 本轮已验证

- 官网 Better Auth 会话可以在数据中心读取姓名、邮箱和头像。
- 官网订阅接口可以驱动 Free / Pro 展示；扩展会员状态作为连接后的第二校验源。
- 扩展外部消息只接受 `https://x.jieyiai.dev`，页面按最多 50 条分页读取 IndexedDB。
- 书签、点赞、本人原创推文、本人回复的采集契约、账号隔离、去重和 Free 1,000 条额度已经实现。
- 表格、画廊、统计、搜索、媒体和日期筛选、标签、文件夹、本地归档、批量 X 写操作已有实现链路。
- 云备份提供 D1 清单、R2 压缩变更块、幂等批次、游标冲突恢复和 30 天保留清理。
- 登录后无扩展、登录后 Pro、扩展返回数据、选择、搜索及三视图已有浏览器回归测试。

## 尚未完成或仍需真实环境验收

1. `关系` 与 `取关历史` 目前只有导航入口，尚未合并旧扩展工作台中的关系数据和取关历史界面。
2. 保存智能筛选、归档恢复入口、单行更多菜单尚未实现，页面已明确标注为开发中。
3. 跨页 CSV / JSON / Markdown / PDF 导出尚未闭环；当前只导出当前页，PDF 使用浏览器打印。
4. 增量同步已限制 5 页、完整同步支持长分页，但“遇到已有高水位停止”和完整同步中断后的服务工作线程级续传仍未实现。
5. GraphQL 查询模板已支持从扩展存储恢复；仍需在真实 X 账号上覆盖 Bookmarks、Likes、UserTweetsAndReplies 与三种写操作的最新 query id。
6. 云备份端到端需要测试 D1/R2 绑定和两个浏览器环境；自动化测试尚未模拟 Cloudflare D1/R2 事务与定时清理。
7. 线上 `https://x.jieyiai.dev/workspace` 当前仍是旧书签工作台，需要部署当前 Worker 静态资源后才会切换到新版数据中心。
8. `LIBRARY_WORKSPACE_ENABLED` 生产配置仍为 `false`，完成真实账号灰度前不应开启生产开关。

## 上线前必测

- Google 登录成功后跳转 `/workspace`，官网与扩展账号一致。
- 新增/取消书签、点赞、发推、回复后增量同步结果正确且无重复。
- 两个设备恢复云备份并验证标签冲突、账号不匹配、Pro 到期只读和 30 天删除。
- 取消书签、取消点赞、删除本人推文逐条核对 X 最终状态。
- 时间线与用户列表的关系胶囊无重复、无空关注率，并覆盖 X 页面 DOM 改版后的选择器。
