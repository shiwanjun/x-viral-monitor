Support

Need help with X-Tools? Please use the links below so we can track and resolve the issue.

Before reporting a problem

  1. Refresh the X page and confirm that X-Tools is enabled in Chrome.
  2. Update the extension from Chrome's extension page or the Chrome Web Store.
  3. Include the page URL pattern (not private content), browser version, extension version, and a screenshot if possible.
