# Chrome Web Store - 商品详情（中文 - 中国）

## 简短说明（132 字符以内）

```
推文爆款检测、互关标识、单向关注检测与取关提醒、长图阅读、Markdown 复制、转发星图与回复辅助——核心本地处理，外部 AI 需主动配置。
```

## 详细说明

```
X-Tools 是 X（Twitter）创作者工具集：爆款检测、关注关系洞察，以及一整套阅读与创作辅助工具。时间线分析保留在本机；只有你主动请求时，相关内容才会直连发送给已配置的 AI 服务商。

⸻ 流速徽章 / 爆款检测 ⸻
• 在每条推文上实时显示"浏览量/小时"徽章，在起爆前先一步看到
• 三档：🌱 普通 · 🚀 上升 · 🔥 爆款
• 通过 popup 自定义阈值
• 鼠标悬停查看详细指标：浏览、点赞、转发、回复、收藏、爆帖指数

⸻ 关注关系洞察 ⸻
• 用户主页显示互关标识
• 单向关注检测（TA 关注了你，或你关注了 TA）
• 曾关注过的人取消关注时给出提醒

⸻ 当前页面热榜 ⸻
• 可拖动的浮动面板，列出当前可见的最快速增长推文
• 点击任意一行跳转到该推文，返回按钮回到原位置
• 列可拖动重排

⸻ 增强图片查看器 ⸻
• 在 X 灯箱里支持触控板捏合 / Ctrl+滚轮缩放、双指 / 拖拽平移、双击切换、+/- /0 快捷键
• 新增：长图阅读模式 — 长截图以 900px 阅读宽度纵向滚动展示，并自动升级到 4096 像素画质，不再被压缩

⸻ Copy as Markdown ⸻
• 在 X 的分享菜单中添加"复制为 Markdown"
• 一键复制作者、日期、链接和正文为干净的 Markdown 格式

⸻ Thank-You 转发星图 ⸻
• 在任意推文的分享菜单点一下，可视化所有转发或引用过这条推文的人
• 可搜索的支持者列表、转发/引用筛选、引用河流时间线

⸻ Grok 回复助手 ⸻
• 调用 X 内置的 Grok 端点（与 X 网页本身使用的同一端点）生成回复草稿
• 提示词模板可编辑、可选"临时聊天"模式（不污染 Grok 历史）

⸻ 工作原理 ⸻
时间线分析在本机完成。网络访问仅限 X、GitHub 规则更新、Pro 授权验证，以及你主动配置并使用的 AI 服务商；无统计、无追踪。

⸻ 隐私 ⸻
✓ 书签文件夹时间线需主动开启，仅从 X 刷新已选择的文件夹
✓ 无统计、无追踪像素；可选 AI 请求只直连你配置的服务商
✓ 所选书签推文最多在本机缓存 24 小时，不同步、不发送到 X-Tools 服务器
✓ 完全开源：https://github.com/Icy-Cat/x-viral-monitor

⸻ 兼容性 ⸻
• 支持 x.com 和 pro.x.com（TweetDeck）
• 界面语言：English / 中文 / 日本語
```
