# XVM 整体迁移:Creem License-Key → Waffo 订阅 + Better Auth (Google 登录)

## 调研确认的技术路径

| 组件 | 结论 | 依据 |
|---|---|---|
| `@waffo/pancake-ts` on Worker | ❌ 不可用(硬依赖 `node:crypto`) | SDK 源码确认 |
| Waffo REST API 直调 | ✅ 签名 `METHOD\nPATH\nTS\nSHA256_BASE64(BODY)`,RSA-SHA256 PKCS#1v1.5,WebCrypto 原生支持 | 官方 auth 文档 |
| Waffo Webhook 验签 | ✅ `X-Waffo-Signature: t=<ms>,v1=<sig>`,签 `${t}.${rawBody}`,用 Waffo 平台公钥(Waffo Dashboard 复制) | 官方 webhooks 文档 |
| Better Auth on Workers | ✅ 1.5+ 原生支持 D1(`database: env.DB`),Hono 挂载 | 官方 1.5 发布说明 |
| Better Auth + Google OAuth | ✅ `socialProviders.google`,回调 `/api/auth/callback/google` | 官方 google 指南 |
| Better Auth + Chrome 扩展 | ✅ **Bearer 插件**:`set-auth-token` 响应头拿 token,`Authorization: Bearer` 发送,无需跨域 cookie;`trustedOrigins` 白名单 `chrome-extension://` | 官方 bearer 插件 + 扩展指南 |
| Waffo Customer Portal | ✅ `pancake.waffo.ai/consumer/portal`,邮箱 magic link 自助管理 | 官方 customer-portal |

## 整体架构(目标)

```
┌─ Chrome Extension (MV3) ────────────────────────────────┐
│  popup Pro tab: 登录/订阅管理 UI                          │
│  src/premium/license/: session 存储、tier 解析            │
│  (gate.js / rate-filter / content-filter: 不动)           │
└──────────┬──────────────────────────────────────────────┬┘
           │ ① Google 登录(浏览器跳转)                      │ ② Bearer token API 调用
           ▼                                                ▼
┌─ Cloudflare Worker "xvm-auth" (Hono) ───────────────────────────────┐
│  /api/auth/*         Better Auth(Google OAuth + Bearer 插件)          │
│  /api/checkout/start 创建 Waffo checkout session(WebCrypto RSA 签名) │
│  /api/subscription/* 查询/状态(读 D1,Bearer 鉴权)                    │
│  /api/webhook        Waffo 回调验签 → 更新 D1                        │
│                                                                      │
│  D1 数据库:                                                          │
│    better_auth:user/session/account/verification(Better Auth 自建)   │
│    subscriptions(id, user_id, plan, waffo_order_id, status, period_end)│
└──────────┬──────────────────────────────────┬───────────────────────┘
           │ WebCrypto RSA 签名                │ webhook
           ▼                                  ▼
     ┌─ Waffo API ─────────────┐    ┌─ Waffo Webhook ─────┐
     │ api.waffo.ai/v1/actions  │    │ subscription.* 事件 │
     │ checkout/create-session  │    └─────────────────────┘
     └──────────────────────────┘
```

## 身份与订阅模型

- **登录**:Google OAuth via Better Auth → 扩展拿到 bearer token 存 `chrome.storage.local`
- **订阅**:登录后点"升级" → Worker 调 Waffo create-session(metadata 带 `userId`)→ 浏览器跳 Waffo 托管页支付 → Waffo webhook 回调 Worker → Worker 写 D1(`subscriptions` 表,关联 `user_id`)
- **tier 解析**:扩展用 bearer token 调 `/api/subscription/status` → Worker 查 D1 返回 `{tier, plan, expiresAt}` → 扩展本地缓存 + 推 `XVM_TIER_UPDATE`
- **管理/取消**:跳转 `pancake.waffo.ai/consumer/portal` 自助

## 阶段 2:Worker 后端(Better Auth + Waffo)

**目录结构(新增,与现有 `worker/license-proxy.js` 并存直到迁移完成):**
```
worker/
├── package.json              # 独立依赖:better-auth, hono, wrangler
├── wrangler.toml             # 更新:D1 binding + name=xvm-auth + trustedOrigins
├── .dev.vars.example
├── tsconfig.json
├── src/
│   └── index.ts              # Hono 入口,挂载 /api/* → auth.handler + 业务路由
├── auth/
│   ├── options.ts            # betterAuth 配置:appName, basePath, Google, bearer 插件
│   ├── instance.ts           # createAuth(env) 工厂:database: env.DB
│   └── schema.sql            # Better Auth 表 + subscriptions 表
└── lib/
    ├── waffo-sign.ts         # WebCrypto RSA-SHA256 请求签名(canonicalRequest 规范)
    ├── waffo-webhook.ts      # Webhook 验签(X-Waffo-Signature 解析 + 公钥 verify)
    └── entitlement.ts        # session token 签发/校验(ECDSA,沿用现有逻辑)
```

**关键实现:**
- `waffo-sign.ts`:PEM 私钥 → `crypto.subtle.importKey('pkcs8', ...)` → 签 `METHOD\nPATH\nTS\nSHA256_BASE64(BODY)` → base64。**零依赖,纯 WebCrypto。**
- `waffo-webhook.ts`:解析 `t=<ms>,v1=<sig>`,验 `${t}.${rawBody}`,5 分钟重放窗口,Waffo 平台公钥(SPKI 格式 importKey)。
- `options.ts`:启用 `bearer()` 插件 + `socialProviders.google` + `trustedOrigins: [chrome-extension://...]`。
- `subscriptions` 表:`id, user_id, plan('standard'|'pro'|'max'), waffo_order_id, status, current_period_end, created_at`

**端点:**
- `ALL /api/auth/*` → Better Auth handler(登录/回调/session)
- `POST /api/checkout/start` `{plan}` → Bearer 鉴权 → 调 Waffo create-session(metadata: `{userId, plan}`)→ 返回 checkoutUrl
- `GET /api/subscription/status` → Bearer 鉴权 → 查 D1 返回 `{tier, plan, expiresAt}`
- `POST /api/webhook` → Waffo 回调 → 验签 → 按 eventType 更新 D1
